Iterative Deepening A* (IDA*)

IDA* is an informed graph traversal and path search algorithm that combines the space efficiency of Depth-First Search with the optimality and completeness of A* search.

f(n) = g(n) + h(n)
g(n)
Path Cost: Exact number of sliding moves made from the initial start state to node n.
h(n)
Heuristic Estimate: An admissible lower bound of the remaining moves to reach the goal configuration.
f(n)
Total Evaluation Function: The estimated total cost of a path passing through state n.

Why IDA* instead of standard A*?

Metric Standard A* IDA* Search
Space Complexity O(bd) — Rapidly runs out of RAM O(d) — Linear memory footprint
Time Complexity O(bd) O(bd) (minor overhead from re-expanding)
Optimality Guaranteed with admissible heuristic Guaranteed with admissible heuristic
Suitability 8-Puzzle (3x3) 15-Puzzle (4x4) and larger sliding tiles

Heuristic Functions

1. Manhattan Distance (L1 Norm)

The sum of horizontal and vertical distances each tile must travel from its current location to its target goal position:

hMD = ∑i=1..15 (|row(i) - goalRow(i)| + |col(i) - goalCol(i)|)

The empty space (tile 0) is ignored in this summation. Manhattan distance is strictly admissible (never overestimates) and consistent (monotonic).

2. Linear Conflict Heuristic

Two tiles tj and tk are in a Linear Conflict if they are in the same goal row (or column), both need to end up in that same line, but their current order is reversed.

Because tiles cannot jump over one another, one of the two tiles must move out of the line to allow the other to pass, which inevitably adds at least 2 extra moves per conflict:

h(n) = hMD(n) + 2 × (Linear Conflicts)

Linear Conflict remains strictly admissible and dramatically reduces the number of IDA* nodes explored by over 90%.

Mathematical Solvability & Parity

Not every random 15-puzzle configuration can be solved! Out of all 16! = 20,922,789,888,000 permutations, exactly half (50%) are solvable.

The 15-Puzzle Solvability Invariant:

For a 4x4 grid (even width):

  • If the blank tile is on an odd row from the bottom (1st or 3rd), the number of inversions must be even.
  • If the blank tile is on an even row from the bottom (2nd or 4th), the number of inversions must be odd.
(inversions + blank_row_from_bottom) mod 2 == 1

Our solver mathematically validates this invariant in O(N) time prior to search invocation, instantly detecting impossible puzzles.

IDA* Algorithm Pseudocode

function IDA_STAR(root):
    threshold = h(root)
    loop:
        (found, min_excess) = SEARCH(root, g=0, threshold)
        if found:
            return solution_path
        if min_excess == ∞:
            return NOT_FOUND
        threshold = min_excess

function SEARCH(node, g, threshold):
    f = g + h(node)
    if f > threshold:
        return (false, f)
    if is_goal(node):
        return (true, f)
    
    min_excess = ∞
    for each child of node:
        (found, excess) = SEARCH(child, g + 1, threshold)
        if found:
            return (true, excess)
        min_excess = min(min_excess, excess)
    
    return (false, min_excess)
