Workflow Overview

How It Works

Solving the 15-puzzle with AI follows three systematic, logical stages.

01

1. Shuffle the Puzzle

The board is scrambled through random legal transitions from the solved state. This guarantees mathematical solvability while creating a challenging search space.

02

2. Run Intelligent Search

The AI initializes IDA* (Iterative Deepening A*). Using the admissible Manhattan Distance heuristic, it traverses game trees without memory blowup, pruning sub-optimal branches.

03

3. Watch the Solution

Once the target path is confirmed, the frontend visually animates every individual tile slide, allowing you to observe, pause, or step through the optimal solution.

Core Concepts

Algorithm Explanation

Understanding the heuristic evaluation function and search mechanics behind optimal 15-puzzle solving.

Heuristic Evaluation Function:
f(n) = g(n) + h(n)
g(n) Actual cost (number of sliding moves) incurred from the start state to node n.
h(n) Heuristic estimate: Total Manhattan Distance from node n to the goal configuration.
f(n) Total estimated path cost through node n to the final solved goal.
Search Strategy

IDA* (Iterative Deepening A*)

The 15-puzzle has over 10.4 trillion reachable states (\(16! / 2\)). Standard algorithms like Breadth-First Search (BFS) or classic A* exhaust available RAM because they store all generated nodes in an open queue.

IDA* solves this memory bottleneck by combining the depth-first search's linear memory footprint (\(O(d)\)) with A*'s optimality. It performs successive depth-first iterations, establishing a cutoff bound on \(f(n)\). In each iteration, branches with \(f(n)\) exceeding the cutoff are pruned, guaranteeing an optimal solution with negligible memory consumption.

  • Space Complexity: \(O(d)\) — only stores nodes along the current search path.
  • Time Efficiency: Iterative bounds avoid expanding excess states.
  • Completeness: Guarantees the shortest solution sequence.
Heuristic Function

Manhattan Distance Heuristic

Manhattan Distance measures the grid-based distance between each tile's current coordinate and its destination coordinate in the solved configuration:

h(n) = \sum_{i=1}^{15} \left( |x_i - x_{\text{goal}, i}| + |y_i - y_{\text{goal}, i}| \right)

Unlike the basic "Misplaced Tiles" heuristic, Manhattan Distance accounts for the minimum number of single-step moves each tile must physically make across rows and columns.

  • Admissibility: It never overestimates the true remaining cost, preserving IDA*'s optimal guarantee.
  • Consistency (Monotonicity): For any move from state \(u\) to \(v\), \(h(u) \le \text{cost}(u,v) + h(v)\).
  • Informed Search: Drastically prunes unpromising search tree branches.
